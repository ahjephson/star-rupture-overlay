# StarRupture Wave Overlay — Windows x64

Extract this complete folder and double-click starrupture-wave-overlay.exe. No configuration, installer, administrator rights, extra runtime or MCP server is required. Version, source revision and per-file hashes are recorded in manifest.json.

Right-click the tray icon to show/hide, unlock/move/lock, reset position or exit. Exit there before starting a different version. The app moves below the pause-menu border and freezes its countdown only when simulation pause is verified. INCINERATING is the game's native Moving phase. Unavailable/stale timer evidence displays --:--.

## Data and updates

The app reads game memory through a read-only handle. No injection, game hooks, writes, save access, network requests or automatic updater. Private discovery caches live under %LOCALAPPDATA%/StarRuptureWaveOverlay/cache and are checked against current identities before reuse.

For updates, compare the ZIP checksum with its matching .sha256 file, extract to a new folder and keep the previous version until verified. The unsigned candidate's checksum establishes integrity, not publisher identity. Uninstall by exiting the app and deleting its extracted folder; caches may be removed separately if desired.
